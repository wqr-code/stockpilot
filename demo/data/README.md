# 家居杂货店示例数据

商品目录来自 [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)，Chen, D. (2015), DOI: 10.24432/C5BW33，CC BY 4.0。
获取日期：2026-09-12；官方 CSV：https://archive.ics.uci.edu/static/public/352/data.csv。

`retail_catalog.json` 保存官方 CSV 中首次出现的前 16 个不同商品的 StockCode、原始英文 Description、首次观察到的 UnitPrice（英镑 GBP），中文名称为翻译。这些是 2010–2011 年历史商品资料和报价，不是当前在售商品或当前市场价格。

`demo/retail_sample.py` 用这份目录生成一个可重复的演示数据集：普通商品 365 天、新品 12 天。销量含周末波动及随机扰动，部分商品设置历史活动、积压库存、缺货、缺失日期或下架状态。

**销量、库存、活动、上架日期、价格底线、折扣与活动效果均为模拟。** 历史报价仅作为演示价格锚点；没有把 UCI 的实际交易序列接入预测，也没有将其价格变化推断成真实促销。模拟活动的销量提升是生成规则，不是现实证据，不能用这份数据证明模型精度或促销因果效果。

`products.csv` 与 `sales.csv` 是同一套演示数据的本地上传文件；导入时选择截止日期 **2026-09-11**。金额统一 GBP。上传接口不会自动识别数据真实性，上传这些文件仍应按模拟数据解释。

公开数据选择：
- UCI Online Retail：真实商品名称、交易时间、数量、成交单价；不包含库存快照、促销标签和缺货状态，适合商品目录及历史交易分析。
- [FreshRetailNet-50K](https://huggingface.co/datasets/Dingdong-Inc/FreshRetailNet-50K)：提供商品时间序列、折扣和缺货相关字段，但商品匿名，适合进一步研究预测与缺货处理，不能直接补全本示例商品的销量。

原有 `operations_sample.py` 保留为算法边界回归测试数据，不再用于网页的“载入示例”。页面仍默认空列表，只有点击载入示例或上传才显示商品。

库存台账更新：示例先生成满足“期末＝期初＋入库－销量”的连续台账，再移除待补录日期。inventory_ledger.csv 可用于核对已知记录。页面缺口未补齐时隐藏当前库存；补录按最早日期开始，默认无入库，后续库存重新计算，负库存拒绝保存。旧版上传 CSV 不含入库字段，暂不支持该库存补录流程；台账 CSV 是核对文件，不是现有上传模板。

上传模板已升级：sales.csv 增加 opening_stock（期初库存）、received_units（当日入库数量，无入库必须填 0）。首条及日期中断后的记录必须提供期初库存，连续日期可留空自动衔接。导入会核对库存公式与商品表末日库存，支持导入后的缺失日期补录。此前关于旧版上传不支持库存补录的说明仅适用于旧格式；旧文件需补齐新列。
